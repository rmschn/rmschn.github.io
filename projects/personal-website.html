This Website and Projects

November 16, 2026

This is the first project post, and the first project was the scripting that generates this website. A few hundred lines of shell and awk that turn Markdown into plain HTML. No build tools. No dependencies. No lock files.

Why?

Static sites are wonderfully boring. There is nothing to patch, nothing to keep running, and the whole thing fits in a Git repository that any free host — GitHub Pages, DigitalOcean, Netlify — will serve without complaint.

I had been using Hugo, but found the templates irritating to be honest. I don't need much, and generally can figure out a way to do just about anything with shell, so thats what happened. Rolled my own.

How it works

1. Drafts live in content/. 2. build.sh reads config.sh for colours and site details. 3. Each Markdown file becomes a page in OUTPUT_DIR. 4. Static assets are copied over unchanged.
